# v1.4 — Visualizador de capturas `.npz`

Adiciona uma ferramenta de linha de comando para inspecionar visualmente os
arquivos `.npz` gerados por `mestre.py` (simulados ou de bancada), sem
precisar abrir um notebook ou escrever um script ad-hoc toda vez.

## Por quê

Cada `.npz` de uma classe guarda várias capturas empilhadas em
`tensao_pu` (`(N, 6000)`, uma linha por captura), não um waveform só — no
modo simulado, `N = SIM_CAPTURES_PER_CLASS` (padrão 2000). Isso não era
óbvio de olhar só o tamanho do arquivo (todas as 20 classes ficam com ~91,6
MB, porque `np.savez` sem compressão grava o array bruto, cujo tamanho só
depende da forma `(2000, 6000)` float64, igual para todas as classes — não
do conteúdo). Um visualizador rápido resolve tanto a inspeção do dado quanto
essa confusão inicial sobre a estrutura do arquivo.

## O que mudou

- **Novo `logica/visualizador.py`**: lê um `.npz` (`tempo_ms`, `tensao_pu`,
  `classe`, `id_captura`) e gera um PNG com 4 painéis — amostra de N
  capturas sobrepostas (mostra a variação da classe), uma captura individual,
  o envelope média±desvio-padrão ao longo de todas as capturas, e um resumo
  textual (classe, shape, tamanho em disco, estatísticas). Abre o PNG no
  visualizador de imagens padrão do SO (`os.startfile` no Windows) ao final,
  a menos que `--sem-abrir` seja passado.
  - Funciona tanto com dados simulados (`N` grande) quanto com dados de
    bancada real (`N=1` por padrão) — com uma captura só, o envelope vira
    uma banda de largura zero, mas não quebra.
  - Opções: `--captura N` (índice específico em vez de aleatório),
    `--n-overlay N`, `--seed`, `--saida caminho.png`, `--sem-abrir`, `--dpi`.
- **Novo `scripts/visualizar_npz.ps1`**: wrapper fino no mesmo padrão dos
  outros scripts de `scripts/` (resolve `$ProjectRoot`, chama
  `env\Scripts\python.exe`).
- **`requirements.txt`**: adiciona `matplotlib==3.11.1` (única dependência
  nova; instalada no venv de desenvolvimento).

## O que **não** mudou

- Nenhuma lógica de geração/captura/gravação de dados (`mestre.py`,
  `experimentos_nativos/`, `experimentos_waveform/`, `sinais.py`) foi
  tocada. O visualizador só lê arquivos já existentes em `resultados/`.
- Formato de saída dos `.npz` idêntico ao da v1.3.
